# Changelog Generator

Generate a structured `CHANGELOG.md` from git history. Auto-categorizes commits using
[Conventional Commits](https://www.conventionalcommits.org/) prefixes, with emoji-rich output.

## Quick Start

### Bash (any system with git)
```bash
# Auto-detect last tag → CHANGELOG.md
./skills/changelog-generator/changelog.sh

# Custom output path
./skills/changelog-generator/changelog.sh --output RELEASE_NOTES.md

# Custom range
./skills/changelog-generator/changelog.sh --range v1.0.0..v2.0.0
```

### Python (cross-platform)
```bash
python skills/changelog-generator/changelog.py
python skills/changelog-generator/changelog.py --output docs/CHANGELOG.md
python skills/changelog-generator/changelog.py --range v1.0.0..HEAD
```

### Claude Code
Load this skill then run:
```
/generate-changelog
```

## Supported Categories

| Conventional Commit Prefix | Category |
|:---------------------------|:---------|
| `feat:` | 🚀 Features |
| `fix:` | 🐛 Bug Fixes |
| `security:` | 🔒 Security |
| `perf:` | ⚡ Performance |
| `deps:`, `bump:` | 📦 Dependencies |
| `refactor:` | ♻️ Refactoring |
| `docs:` | 📝 Documentation |
| `style:` | 🎨 Style |
| `test:` | 🧪 Tests |
| `build:`, `ci:` | 🏗️ Build / CI |
| `chore:` | 🔧 Chores |
| *(no match)* | 📌 Other Changes |

Commits without a Conventional Commit prefix are categorized by their first word
(e.g., `Add`, `Fix`, `Remove`, `Security`, `Perf`, etc.).

## Options

### Bash (`changelog.sh`)

| Flag | Description | Default |
|:-----|:------------|:--------|
| `--output FILE` | Write output to FILE | `CHANGELOG.md` |
| `--range RANGE` | Git revision range | `latest_tag..HEAD` |
| `--help`, `-h` | Show help | — |

### Python (`changelog.py`)

| Flag | Description | Default |
|:-----|:------------|:--------|
| `--output FILE`, `-o` | Write output to FILE | `CHANGELOG.md` |
| `--range RANGE`, `-r` | Git revision range | `latest_tag..HEAD` |
| `--help`, `-h` | Show help | — |

## Output Format

```markdown
# repo-name — Changelog

## [v1.2.0] — 2026-07-28

### 🚀 Features

- feat: add dark mode support
- feat(auth): implement OAuth2 login

### 🐛 Bug Fixes

- fix: resolve navbar overflow on mobile
- fix(api): handle null response from /users

### 📝 Documentation

- docs: update API reference

---

*Generated by changelog-generator*
```

## Requirements

- **Bash version**: `git` installed, Bash 4.0+ (for associative arrays)
- **Python version**: `git` installed, Python 3.8+
- Works on Linux, macOS, and Windows (Git Bash / WSL)

## Error Handling

| Scenario | Behavior |
|:---------|:---------|
| Not a git repo | ❌ `Error: Not a git repository.` (exit 1) |
| No commits in range | ❌ `Error: No commits found in range.` (exit 1) |
| No tags (first release) | ✅ Falls back to first commit, version = `Unreleased` |
| Empty repo | ❌ `Error: No commits found in this repository.` (exit 1) |
